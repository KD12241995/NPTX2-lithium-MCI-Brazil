# Data Directory

This directory contains input data files required to run the analysis notebooks,
and receives output files generated by the notebooks.

---

## `input/` — Required Input Files

Place the following files here before running the notebooks.
All files are available upon reasonable request from the corresponding author.

| File | Used by | Description |
|------|---------|-------------|
| `Separated_Lithium_Group_Visit_Differences.csv` | `00`, `01` | Per-patient visit-difference data for the Lithium arm (CSF proteins + demographics) |
| `Separated_Placebo_Group_Visit_Differences.csv` | `00`, `01` | Per-patient visit-difference data for the Placebo arm |
| `Lithemia_Lithium_forPearson.xlsx` | `01` | Plasma lithium concentrations (Litemia) with CSF protein and demographic columns, for the correlation analysis in Fig. 1B–1I |
| `Final_statistical_analysis.xlsx` | `02` | Master statistical analysis table (baseline proteomics; Sheet1 format with `Group` column and `_ELISA`/`_NULISA`/`_PRM` columns) |
| `figure3_NULISA.xlsx` | `03` | Pre-computed per-protein Pearson r and p-values across four groups (Base placebo, Baseline lithium, 1y placebo, 1y lithium) for NULISA panel; used to generate bubble plot figure |
| `Nulisa_PRM_combined_analysis_lithium.xlsx` | `03` | NPTX2-centered pairwise correlation table for the Lithium group (NULISA + PRM-MS combined) |
| `Nulisa_PRM_combined_analysis_placebo.xlsx` | `03` | NPTX2-centered pairwise correlation table for the Placebo group (NULISA + PRM-MS combined) |
| `Final_statistical_analysis_YWHAZ_NPTX2_demographic.xlsx` | `04` | Statistical table containing YWHAZ:NPTX2 ratio columns (ELISA/NULISA/PRM) and cognitive/demographic variables at baseline and 1-year |
| `Visit_Differences_YWHAZtoNPTX2.xlsx` | `04` | Longitudinal change scores (visit 0 → visit 1) for YWHAZ:NPTX2 ratios and cognitive measures |

### Column naming conventions

- Assay columns end with `_ELISA`, `_NULISA`, or `_PRM`
- Group labels follow: `Lithium_base`, `Placebo_base`, `Lithium_1y`, `Placebo_1y`, `Lithium_3y`, `Placebo_3y`
- Visit-difference columns follow: `{variable}_diff_visit_0_vs_1`

---

## `output/` — Generated Output Files

The notebooks write results here automatically. Key outputs include:

| File | Generated by | Description |
|------|-------------|-------------|
| `Litemia_Correlation_Results.xlsx` | `01` | Pearson r and p-values: plasma lithium vs. all CSF protein changes |
| `Lithium_ELISA/PRM/NULISA_Correlation_Results.xlsx` | `00` | Within-group pairwise correlations by assay type |
| `correlation_all_combined.xlsx` | `02` | Baseline demographic × proteomics correlation results |
| `protein_categories_lithium/placebo.xlsx` | `03` | Protein lists categorized by significance pattern |
| `statistical_analysis_summary.xlsx` | `03` | McNemar / Fisher z-transform statistics |
| `figure3_NULISA_main.png` / `.pdf` | `03` | Publication figure (bubble plot) |
| `YWHAZtoNPTX2_correlation_results.xlsx` | `04` | YWHAZ:NPTX2 vs. cognitive outcomes at baseline/1y |
| `YWHAZtoNPTX2_correlation_results_change.xlsx` | `04` | YWHAZ:NPTX2 change vs. cognitive change scores |
